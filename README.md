🛠️ CodeFix – Smart Java Auto-Correction & Debugging Tool
CodeFix is a rule-based Java debugging and syntax auto-correction tool built using Java, JavaFX, and SQLite. Designed with a futuristic neon cyberpunk theme, CodeFix offers an interactive interface to analyze Java code, highlight issues, and provide smart, automated corrections — without using any AI libraries.

✨ Features
🔍 Syntax Error Detection
Analyzes Java code using a rule-based parser to detect common syntax errors.

🧠 Auto-Correction Engine
Applies predefined correction rules to fix common errors automatically.

📋 Suggestion Panel
Displays line-by-line suggestions for manual or automatic correction.

🧬 JDBC Integration
Uses SQLite and Oracle JDBC to store and retrieve logs, corrections, and history.

🎨 Custom UI Theme
Neon-glow UI with cyberpunk aesthetics using pure JavaFX (no FXML).

📁 File Menu
Includes File/Open, Save, Print, and Theme toggle options.

🛠️ Editor Panel
Real-time syntax checking, highlighting, and debug tools.

⌛ Loading Animation
Animated startup screen to enhance UX.

🔧 Technologies Used
Java 17+

JavaFX (UI & styling)

JDBC (for database connectivity)

SQLite (for local storage/logging)

Oracle SQL (for enterprise mode)

Java I/O (File reading/writing)
